# Full Stack Phonebook Application

This is a full-stack application that stores phonebook entries. The frontend is built with React and the backend is built with Node.js and Express.

## Live Application
[Click here to access the Phonebook](https://fullstack-open-4pcw.onrender.com)

## API Endpoints
- **GET all entries:** [https://fullstack-open-4pcw.onrender.com/api/persons](https://fullstack-open-4pcw.onrender.com/api/persons)
- **GET info page:** [https://fullstack-open-4pcw.onrender.com/info](https://fullstack-open-4pcw.onrender.com/info)

## Technologies Used
- Frontend: React, Axios
- Backend: Node.js, Express, Morgan, CORS
